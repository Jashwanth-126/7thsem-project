# KrishiMitra - Agricultural Marketplace & Supply Chain Traceability Platform

KrishiMitra is a decentralized agricultural marketplace and crop traceability platform connecting Farmers, Primary Farmer Organizations (PFOs), Dealers, Retailers, and Customers.

## Features
- **Farmer Dashboard**: List crops, track quality verification, view active auctions, and receive payments.
- **PFO Dashboard**: Inspect crops, grade quality, generate QR verification codes, and monitor district trades.
- **Dealer & Retailer Workflows**: Bid on verified crops, handle escrow payments, and track dispatch and transport.
- **Supply Chain Traceability**: End-to-end QR code tracking from harvest to consumer delivery.
- **Customer Storefront**: Browse retail inventories, place orders, and trace product journey via QR code.

## Tech Stack
- **Frontend**: React, Vite, TailwindCSS, React Router
- **Backend**: Python, Flask, Supabase
- **Database & Storage**: PostgreSQL (Supabase), Supabase Storage
- **Deployment**: Vercel (Services monorepo)
